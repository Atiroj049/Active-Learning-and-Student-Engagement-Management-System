# aunqa-p5

Active Learning and Student Engagement Management System — Team T07

**ระบบบริหารกิจกรรมการเรียนรู้เชิงรุกและการมีส่วนร่วมของนักศึกษา**

หลักสูตรวิศวกรรมซอฟต์แวร์ มหาวิทยาลัยเทคโนโลยีราชมงคลล้านนา · ENGSE211 / ENGSE212 / ENGSE601

## ภาพรวม

โครงงานเว็บแอปสำหรับบริหารกิจกรรมและการอบรมที่หลักสูตรรับผิดชอบ เป็นระบบย่อย P5 ในแพลตฟอร์ม SE AUN-QA โดยมีขอบเขตตาม SRS ดังนี้

| ส่วนงาน | หน้าที่ |
|---|---|
| **ข้อมูลกิจกรรม** | บันทึกเป้าหมาย วันเวลา สถานที่ ข้อมูลอ้างอิงการอนุมัติ และเกณฑ์ชั่วโมง พร้อมเลือกเชื่อมโยง PLO/CLO จากข้อมูลอ้างอิงกลาง |
| **การลงทะเบียน** | เปิดหรือปิดรับลงทะเบียน ตรวจรหัสอ้างอิงนักศึกษา และป้องกันการลงทะเบียนกิจกรรมเดิมซ้ำ |
| **การเข้าร่วมและชั่วโมง** | ผู้มีสิทธิ์ตรวจหลักฐานและบันทึกข้อมูลในขั้นตอนเดียว รวมเฉพาะชั่วโมงที่ตรวจสอบครบ และเก็บประวัติการแก้ไขโดยไม่นับซ้ำ |
| **Reflection** | ผู้จัดกำหนดข้อความคำถาม 3 ข้อต่อกิจกรรม นักศึกษาส่งหรือแก้ไขคำตอบได้ตามสิทธิ์และช่วงเปิดรับ |
| **สรุปผลและประวัติ** | แสดงยอดลงทะเบียน เข้าร่วมจริง และตอบ Reflection แยกกัน พร้อมประวัติชั่วโมง ผลตามเป้าหมาย และข้อเสนอปรับปรุงกิจกรรม |
| **รายงานและหลักฐาน** | แนบหลักฐาน จัดทำ PDF/XLSX และส่งชุดหลักฐานจากรายงานที่ผู้จัดตรวจรับรองแล้วให้ P1 ตาม IF05 |

ผู้ใช้หลักประกอบด้วยนักศึกษา ผู้จัดกิจกรรม และผู้บันทึกการเข้าร่วม โดยผู้จัดและผู้บันทึกอาจเป็นบุคคลเดียวกัน ระบบจำกัดสิทธิ์ตามข้อมูลของตนเองหรือกิจกรรมที่ได้รับมอบหมาย

ยอดชั่วโมงครอบคลุมเฉพาะกิจกรรมที่มีข้อมูลใน P5 ส่วนการอนุมัติจัดกิจกรรม การรับรองชั่วโมงอย่างเป็นทางการ การออก Activity Transcript และการตัดสินการสำเร็จการศึกษาเป็นหน้าที่ของหน่วยงานที่เกี่ยวข้อง

## เทคโนโลยี

- Frontend: Next.js (React) + TypeScript
- Backend: Node.js + Express.js (REST API)
- Database: PostgreSQL
- File Storage: พื้นที่ไฟล์ส่วนตัว โดยตรวจสิทธิ์ก่อนเข้าถึงหลักฐาน
- สถาปัตยกรรม: แยกส่วนติดต่อผู้ใช้ API และฐานข้อมูล พร้อมแลกเปลี่ยนข้อมูลกับระบบส่วนกลางตามข้อตกลง IF01, IF05 และ IF09
